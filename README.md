# EAA / EAQE 自擬複習閃卡（Round 11）

**這不是地產代理監管局或香港特區政府的官方材料，亦未經其認可或背書；只是用 AI 生成的自用複習題目，供個人備考練習。**

本包**不是**官方歷年真題，也**不是**官方參考題／樣題原卷。請到官網自行下載官方資料。

本包只包含自行編寫的閃卡（Anki `.apkg` 和 TSV 文本備份），**不含任何官方 PDF**。

法例、考試安排和官方資料可能更新，請以監管局最新公布和香港電子法例的現行文本為準。

## 內容與題量

請任選一種方式導入，**不要把「全部」和「僅章節／僅仿真／單章」重複導入**，以免牌組疊加。

| 檔案 | 格式 | 題量 |
| --- | --- | ---: |
| `EAA_EAQE_all.apkg` / `EAA_EAQE_all.tsv` | Anki 牌組／文本備份 | 1800（章練 800 + 仿真 1000） |
| `EAA_EAQE_chapters_only.apkg` / `.tsv` | 同上 | 800（八章練習，每章 100 題） |
| `EAA_EAQE_mocks_only.apkg` / `.tsv` | 同上 | 1000（仿真 20 套，每套 50 題） |
| `EAA_ch01.apkg` … `EAA_ch08.apkg` | Anki 牌組 | 各 100 題 |

本包無配圖，Anki 包內不需要額外的 `media` 資料夾。可用 `SHA256SUMS.txt` 核對檔案完整性。

牌組結構：

- `EAA::章節練習::第一章` … `第八章`
- `EAA::仿真試卷::第01套` … `第20套`

卡片正面為題幹和選項，背面為答案與解說。

完整的 AnkiDroid 下載、安裝、導入和複習步驟，見同目錄的 [AnkiDroid使用教程.md](AnkiDroid使用教程.md)。

## 導入方法

本包主要供 Android 上的 **AnkiDroid** 使用。請先閱讀 [AnkiDroid使用教程.md](AnkiDroid使用教程.md)。

請只導入**一個** `.apkg`。一般使用者建議導入 `EAA_EAQE_all.apkg`。**不要把「全部」和「僅章節／僅仿真／單章」重複導入**，以免牌組疊加。

AnkiDroid **不能直接導入** `.tsv` 文本檔。`.tsv` 只供電腦版 Anki 備份導入：在電腦版 Anki 選擇「導入」，勾選「允許 HTML」，欄位分隔符為 Tab。檔案開頭已含 Anki 文本導入標記（`#separator:tab`、`#html:true` 等）。

電腦版 Anki：打開 Anki，「檔案」→「導入」，選擇 `.apkg`。

iPhone（AnkiMobile）：用 AirDrop 或「檔案」App 打開 `.apkg`，選擇用 Anki 導入。
